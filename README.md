# Portafolio — José de Jesús Ramos

Portafolio personal donde muestro un poco de mí, mis proyectos y las tecnologías con las que trabajo.

Construido con React, Vite, TypeScript y Tailwind CSS.

## Ejecutar en local

```bash
npm install
npm run dev
```

## Despliegue

El sitio se publica en GitHub Pages automáticamente con GitHub Actions (`.github/workflows/deploy.yml`).
